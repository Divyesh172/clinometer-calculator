💡 Clinometer Trigonometry Guide

1. Baseline Distance (d)

Measure horizontal ground distance from the observer to the base of the object using tape or paces.

2. Tilt Angle (θ)

Sight the apex of the object through the clinometer. The angle θ between horizontal and sightline is measured.

3. Trigonometry Formula

In a right triangle: tan(θ) = Opposite / Adjacent.

Rise (h) = Distance × tan(θ)

4. Observer Eye Height

Add the vertical height from ground to observer eyes:

Total Height = Rise (h) + Eye Height (heye)

🛠️ Homemade Protractor Clinometer

  1. Fasten a straight straw along the 90° baseline of a protractor.
  2. Tie a weighted string (plumb line) to the center hole.
  3. Sight apex through straw: Tilt θ = |90° − plumb angle|.
